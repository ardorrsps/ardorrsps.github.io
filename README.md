# Ardor — web client

The browser build of the Ardor game client, compiled to JavaScript. This
repository holds **only the published output**: one HTML page, a boot script,
the compiled bundle, and a small config file.

## About this repository

The source is not public; only this generated bundle is. Every deploy
force-pushes a single orphan commit, so there is no history here and any
change made directly to this repository is overwritten by the next deploy —
including edits to this file, which is generated by the build.

The bundle is obfuscated but not secret: anything the browser downloads can
be read. The server endpoints in `config.js` are public by design, since the
page cannot connect without them.
